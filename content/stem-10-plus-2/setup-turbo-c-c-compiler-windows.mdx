Well ! Very worm welcome friends. Today we know how to setup Turbo C++ Compiler for windows. This tutorial gives you easy-to-follow instructions, with screenshots, for setting up a compiler step by step.

## Setup Turbo C or C++ compiler step by step:

## Step 1: Download Turbo C++

 	
- Go to this website:[ https://turboc.codeplex.com/](https://turboc.codeplex.com/)
 	
- Follow the link to "Download the binary release" ([direct link](https://turboc.codeplex.com/downloads/get/1489512))
 	
- If any previous "Turbo C++" version install in your computer, then first of all uninstall that.
 	
- * *Extract downloaded "*Turbo C++ 3.2.zip*" file.

## Step 2: Install

Run "*setup.exe*" file and Follow the setup instructions.

 

[![Setup Turbo C](http://technhit.in/wp-content/uploads/2016/04/inst1.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst1.jpg)

When Configuring process is completed you will be prompted for* Next.*

[![inst2](http://technhit.in/wp-content/uploads/2016/04/inst2.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst2.jpg)

 

Click On Next Button for proceeding next step.

[![inst3](http://technhit.in/wp-content/uploads/2016/04/inst3.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst3.jpg)

If you have enough time in your hand then read the full license agreement then you have to accept the *license agreement radio button* then click on *Next.*

[![inst4](http://technhit.in/wp-content/uploads/2016/04/inst4.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst4.jpg)

Click on *Install Button* ->

[![inst5](http://technhit.in/wp-content/uploads/2016/04/inst5.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst5.jpg)

Wait until installation is completed.

[![inst6](http://technhit.in/wp-content/uploads/2016/04/inst6.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst6.jpg)

Click on *Finish Button* ->

[![inst7](http://technhit.in/wp-content/uploads/2016/04/inst7.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst7.jpg)

From the landing window you see some links that helps you to manage your project. In the start section you can create a new project, open a project, create a new source file like a single file for short program. If you are new to programming language you can learn from example. In turbo C++ there are very well defined and well documented examples, from where you can learn many more about function, operators, constructor.

Lets click on *Start Turbo C++ Button* marked with red circle.

[![inst8](http://technhit.in/wp-content/uploads/2016/04/inst8.jpg)](http://technhit.in/wp-content/uploads/2016/04/inst8.jpg)

Finally you can start coding by creating a new file from *file menu.*
