In general, printf** **()** ** is a library function under C header file *stdio.h* and *conio.h* both. And generally, it is used for displaying an outcome of a program to outside world. **Printf()** function is often used to our program to do formatted output. All variants of printf function use same formatting techniques. There is a string that specifies the layouts of output is call format specifier. i.e. %s, %d, %f, %c, %x, %u etc.

rnThis function uses first format specifier for the first argument, second format specifier for the second argument and so on. There must be enough arguments for each format specifier otherwise, the result will be unpredictable due to less argument. And excess arguments are merely ignored. Format specifier determines how and what kind of data types will print to screen. There are various format specifiers you can use, these are:

rnrn
rn 	- *%c   ->char single character*
rn 	- *%d (%i) ->int signed integer*
rn 	- *%e (%E) ->float or double exponential format*
rn 	- *%f ->float or double signed decimal*
rn 	- *%g (%G) ->float or double use %f or %e as required*
rn 	- *%o ->int unsigned octal value*
rn 	- *%p ->pointer address stored in pointer*
rn 	- *%s ->array of char sequence of characters*
rn 	- *%u ->int unsigned decimal*
rn 	- *%x (%X) ->int unsigned hex value*
rn
rnIn turbo C  there are seven variants of printf function to do the different specific job. These are:rn
rn 	- printf*()   -> sends formatted output to a standard output device*
rn 	- cprintf*() -> sends formatted output to a text window on the screen*
rn 	- sprintf*() -> sends formatted output to a string (sends to an array in memory)*
rn 	- fprintf*() -> sends formatted output to a File stream*
rn 	- vprintf*() -> sends formatted output to stdin using an argument list*
rn 	- vfprintf*()->sends formatted output to a File using an argument list*
rn 	- vsprintf*()->sends formatted output to a string using an argument list*
rn
rn## Here prefix of printf f,s,v,c stands for:

rn
rn 	- *f -> means it takes a FILE* param to write to.*
rn 	- *s -> means it writes to a string buffer.*
rn 	- *v ->means it takes all the value args as a single vector (array).*
rn 	- *c ->means it write to the console (Text window on the screen)*
rn

rnrn## vprintf**():**

rnPrint formatted data from variable argument list to stdout. It writes the C string pointed by format to the standard output (stdout), replacing any format specifier in the same way as printf does, but using the elements in the variable argument list identified by arg instead of additional function arguments.

rnInternally, the function retrieves arguments from the list identified by arg as if va_arg was used on it, and thus the state of arg is likely altered by the call.

rnIn any case, arg should have been initialized by va_start at some point before the call, and it is expected to be released by va_end at some point after the call.

rnrn#### Prototype of vprintf:

rn```

```rn### parameters:

rn[*Format*](#jump1)

rnFormat specifier prototype for vprintf function:

rn*arg ->** A value identifying a variable arguments list initialized with va_start.*rn*va_list is a special type defined in <cstdarg>.*
