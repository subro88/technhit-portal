React. js is an open-source JavaScript library that is used for creating web frontend and UI components specifically for single-page applications. It's used for handling the view layer for web and mobile apps. It is developed and maintained by Facebook and a large community of developers.

rnrn## History of React JS

rnReact was created by Jordan Walke, a software engineer at Facebook, who released an early prototype of React called "FaxJS". It was first deployed on Facebook's News Feed in 2011 and later on Instagram in 2012. And finally, it was open-sourced at JS Conference US in May 2013. And as a result, the Reacts first release was published in 2013.
