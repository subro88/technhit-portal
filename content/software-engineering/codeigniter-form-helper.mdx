rn**form_input( )** function allow us to generate a standard text input field. ```rnrnThe above code will produce the following HTML tag:-rnrn```
<input type="text" name="emp_name" value="" id="emp_name_id" placeholder="Please Enter Name"  />
```rnrnForm Input with Read-only permission:-rnrnAn input field can be created with **read-only **permission by passing ‘readonly’ as an index and value both in the associative array of form_input() function.rnrnAn example of input field with read-only permission is given below:-rnrn```
 $data_name = array(rn'name' => 'emp_name',rn'id' => 'emp_name_id',rn'value' => 'John'rn'readonly' => 'readonly'rn);rnecho form_input($data_name);
