CodeIgniter is light weight Open source powerful PHP Framework for web application development. It has many powerful features that make it popular. CodeIgniter is more compatible with any type of hosting and it has a very low footprint.  It is also compatible with PHP4 and PHP5, so CodeIgniter can run on most of the web hosts out of there.

rnThe main principle of CodeIgniter is MVC (Model View Controler) design pattern, Which segregates your application into three deferent parts:

rnrn
rn 	- Model --- Model is the database abstraction layer where all database operations are performed.
rn 	- View --- View is the front end user interface or template from where users interact with the application.
rn 	- Controllers --- Controllers are the logic of your application from where your entire application directives are operated.
rn
rnCodeIgniter has inbuilt libraries and helpers for the database, URL, cache etc that make it easier, effective and less coding Framework rather than other Frameworks. Now move on and setup CodeIgniter on your local environment.
