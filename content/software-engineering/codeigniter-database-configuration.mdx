In continuation of basic configuration tutorial, now we are going to configure our database for the web application. The database is most important (Backbone) part of any application for storing and retrieve information an organised manner. In CodeIgniter **database configuration** comes in ***database.php*** under** */application/config*** directory. CodeIgniter currently supports following database to build any web application:

rnrnrnrnrn
rn 	- MySQL (5.1+) via the *mysql* (deprecated), *mysqli* and *pdo* drivers
rn 	- Oracle via the *oci8* and *pdo* drivers
rn 	- PostgreSQL via the *postgre* and *pdo* drivers
rn 	- MS SQL via the *mssql*, *sqlsrv* (version 2005 and above only) and *pdo* drivers
rn 	- SQLite via the *sqlite* (version 2), *sqlite3* (version 3) and *pdo* drivers
rn 	- CUBRID via the *cubrid* and *pdo* drivers
rn 	- Interbase/Firebird via the *ibase* and *pdo* drivers
rn 	- ODBC via the *odbc* and *pdo* drivers (you should know that ODBC is actually an abstraction layer)
rn

rnrn</footer>rn**Hostname--** In this parameter specify the database server location. If your database locates the same server where your application runs use "*localhost*" for hostname parameter. If your database server runs from the different server then you have to put *Domain name* or* IP* address of database server.

rn**Username--** In this parameter tell your database user name.

rn**Password--** In this parameter specify your database password.

rn**Database--** In this parameter specify your database name.

rn**Dbdriver--** In this parameter set your database type. For example *MySQL, MySQLi, Postgre SQL, ODBC, and MS SQL* etc.
