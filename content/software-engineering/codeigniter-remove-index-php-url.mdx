Everyone should want to remove trailing index php from URL after installing CodeIgniter. Removing Index.php from URL, it looks clean and more search engine friendly. That's why you want too. You can remove index php part of the URL by adding a*** "<strong>.**htaccess"*</strong> file to the root of your CodeIgniter install.
