MySQL Replication is a method, which uses for sync database two or more replica servers. Typically it's known as "Master-Slave" Replication.

rnWe have extended this configuration from Master-Slave to Master-Master Mode. Generally, in Master-Slave Mode there is a one master server with read write access. And one or more replica servers that only replicate the master. In a simple word, any thing changes in the master server is reflected on slaves but any changes in slaves do not reflect on the master. But in Master-Master mode replication is take effect both master to slave and slave to master. That's why it's called Master Master Mode.

rnSo, now we start config with Master-Slave mode and finally convert it to Master-Master mode.rn## **Environment and Prerequisites for MySQL Replication: **
