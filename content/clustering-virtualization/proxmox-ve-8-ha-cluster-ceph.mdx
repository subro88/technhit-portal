# High Availability Proxmox VE 8 Cluster with Ceph Storage

Building a quorum-backed 3-node virtualization cluster allows virtual machine live migration without 1 millisecond of packet loss or downtime.

<InfoBox title="Quorum Safety Guideline" type="note">
Never build a two-node cluster without a low-cost QDevice Raspberry Pi witness to avoid split-brain failure scenarios.
</InfoBox>

### 1. Initialize Corosync Cluster Link

Run the initialization sequence on node 1 with dedicated 10GbE corosync ring links:
