Today's world is growing very fast and everyone is in a hurry! According to a [Google](https://developers.google.com/web/fundamentals/performance/why-performance-matters/) study, 40% of people abandon a website that takes more than 3 seconds to load and a 1-second delay in page response can result in a 7% reduction in conversions. Yes, every second matters! hence Brotli comes into effect to speed up your website.

rnJust like Gzip, Brotli is also a generic-purpose compression algorithm developed by Google. It compresses data using a combination of modern technologies and algorithms. It is similar in speed to deflate but provides higher compression. Brotli compression is supported by all the major browsers like Chrome, Firefox, Safari, Edge.

rnIn this Article we are going to configure Brotli Compressor Mechanism with Apache Web Server.

rnrn## See on Youtube:

rn[embedyt] https://www.youtube.com/watch?v=0ZjTC9wJ1RM[/embedyt]rn## Prerequisites

rn
rn 	- Need sudo  privileged account.
rn 	- Assumed that you have Apache webserver running with a Virtual host which serving web content.
rn
rnWell, at this point we understand that Brotli can help you to speed up your heavy website, and save your bandwidth also. And eventually, it helps optimization on SEO ranking in the competition market.

rnWe assume that you have an existing web server with Apache in order to do the experiment, and if you are in a production environment then I strongly recommend to make a backup your files before that. You can also check out this video how to setup Apache Vhost above here.

rnGo ahead and open terminal type :

rnrn```
sudo apt install brotli 
```rnSo, after install Brotli, enable the module in Apache.

rnrn```
sudo a2enmod brotli 
```rnNow You need to restart Apache2 in order to make module effective.

rnrn```
sudo systemctl restart apache2 
```rnNow, open up Apache Vhost config file. go ahead and type `nano /etc/apache2/site-available/<your config file>`.

rnInside your config file place cursor after directory tag and put an If Module.

rnrn```
<VirtualHost *:80>rn    ServerName myapp1.comrnrn    ServerAdmin admin@myapp1.comrn    DocumentRoot /var/www/html/wordpress/rnrn    <Directory /var/www/html/wordpress>rn        Options Indexes MultiViewsrn        AllowOverride Allrn        Require all grantedrn    </Directory>rn/////////////////////////////// Add this config to your Vhost file ////////////////////////////rn    <IfModule mod_brotli.c>rn        AddOutputFilterByType BROTLI_COMPRESS text/html text/plain text/xml text/css text/javascript application/javascriptrn    </IfModule>rn///////////////////////////////////////////////////////////////////////////////////////////////rnrn    ErrorLog ${APACHE_LOG_DIR}/error.logrn    CustomLog ${APACHE_LOG_DIR}/access.log combinedrn</VirtualHost>rn
```rn rnInside If Module add output filter type Brotli Compress, and then put your file type you want to compress. So, here is put html, css, Js etc.

rnAfter that save the configuration and exit. And again, restart the Apache service in order to make effect in your website.

rnrn```
sudo systemctl restart apache2 
```rnNow open up the browser and load the page in another tab, it will be bit faster than previous. You could check whether your Brotli Compressor work or not, using Curl command. So, open a local terminal and type the following command.

rnrn```
curl -I -H 'Accept-Encoding: br' http://myapp1.com 
```rnYou can see the output that content encoding Brotli is working fine for me.
