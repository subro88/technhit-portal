rnrn## What is a virtual host? And its uses.

rnWell, the term Virtual Host refers to the practice of running more than one web site such as company1.example.com and company2.example.com and so on within a single machine. Virtual hosts can be "IP-based", meaning that you have a different IP address for every web site, or "name-based", meaning that you have multiple names running on the same IP address.

rnSo, the fact is that they are running on the same physical server but it is not apparent to the end-user. Means Company1 does not have access to Company 2’s files and whatever inside going on. Thus, it secure and reliable.

rnIn the real world, we often called this method shared web hosting. The price for shared web hosting is much lesser than a dedicated web server because many customers can be hosted on a single server.

rn### Step-1) Update the package list

rnFirst thing is first, do update your package list. Go ahead and type

rnrn```
 sudo apt update
```rn### Step-2) Install Apache HTTP Server

rnAfter updating the package list, you need to be installed apache into your system.

rnrn```
sudo apt install apache2
```rnAfter installing Apache, you could check it perfectly running or not by using the service command

rnrn```
 service apache2 status
```rn### Step-3) Creating User for Virtual Host

rn Now we are going to create two users for this experiment one is userA and other is userB. Let’s go and type

rnrn```
sudo useradd -m userArnsudo useradd -m userB
```rnHere the flag -m will Create the user's home directory if it does not exist. Now create a directory named public_html inside each user’s directory. Go ahead and type

rnrn```
sudo mkdir /home/userA/public_htmlrnsudo mkdir /home/userB/public_html
```rnNow we have a public_html directory under each user’s directory.

rnrn### Step-4) Creating Index File

rnNow you need to put some markup text inside public_html to identify your virtual host. So, we are gonna create an index.html file under public_html directory. Go ahead and type

rnrn```
sudo nano /home/userA/public_html/index.html
```rnAnd put this markup text and save the file.

rnrnrn```
<html>rn   <head>rn      <title>Welcome to abc.com</title>rn   </head>rn   <body>rn      <h1>Hello! There welcome to abc.com page</h1>rn   </body>rn</html>
```rnrnAnd similarly, do the same for user B.

rnrn```
sudo nano /home/userA/public_html/index.html
```rn```
<html>rn <head>rn <title>Welcome to xyz.com</title>rn </head>rn <body>rn <h1>Hello! There welcome to xyz.com page</h1>rn </body>rn</html>
```rnNow each user had their index file ready to serve over apache.

rnrn### Step-5) Creating Apache Virtual Host Config

rnNow it’s time to create vhost config file for each user, go ahead and type

rnrn```
sudo nano /etc/apache2/site-available/abc.com.conf.
```rnSo, now you need to tell apache about your vhost and its configuration. Actually, these are called tags and directives.

rnrnrn```
<VirtualHost *:80>rn ServerAdmin abc@abc.comrn ServerName abc.comrn ServerAlias www.abc.comrn DocumentRoot /home/userA/public_html/rn<Directory /home/userA/public_html/>rn Options Indexes FollowSymLinksrn AllowOverride Nonern Require all grantedrn</Directory>rn ErrorLog ${APACHE_LOG_DIR}/error.logrn CustomLog ${APACHE_LOG_DIR}/access.log combinedrn</VirtualHost>
```rnrnSo, roughly this is a standard Virtual Host structure which I made here, and my recommendation is first to understand your needs and then place the configuration. Do not blindly copy-paste from any tutorial in your production server. This can bring disaster at any time.

rn[Or you could learn more about directives and Virtual host examples at apache documentation just open up the documentation. ](https://httpd.apache.org/docs/2.4/vhosts/examples.html)

rnNow we are going to create another Virtual host configuration for xyz.com

rnrn```
sudo nano /etc/apache2/site-available/xyz.com.conf.
```rn```
<VirtualHost *:80>rn ServerAdmin abc@abc.comrn ServerName abc.comrn ServerAlias www.abc.comrn DocumentRoot /home/userA/public_html/rn<Directory /home/userA/public_html/>rn Options Indexes FollowSymLinksrnAllowOverride NonernRequire all grantedrn</Directory>rn ErrorLog ${APACHE_LOG_DIR}/error.logrn CustomLog ${APACHE_LOG_DIR}/access.log combinedrn</VirtualHost>
```rnSo, after all this stuff you need to enable your sites. Go ahead and type

rnrn```
sudo a2ensite abc.comrnsudo a2ensite xyz.com
```rnAnd finally restart the apache, type

rnrn```
sudo systemctl restart apache2.
```rn### Step-6) Add Local DNS Resolver

rnNow, one last thing you needed is that a local DNS resolver as we are in a local environment, so, edit your hosts file using nano editor and add a local DNS record for each host. And if you are in a production environment then point your public IP to your DNS manager.

rnrn```
sudo nano /etc/hosts
```rnAnd add the following lines at the endrn```
127.0.0.1   abc.comrn127.0.0.1   xyz.com
```rn### Step-7) Test your Virtual Host

rnFinally, test your settings, open up the web browser and open xyz.com and you could see the web page serving from xyz vhost.
