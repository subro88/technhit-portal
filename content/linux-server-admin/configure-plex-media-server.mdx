rnrn**Plex** is a client-server media player system. Plex Media Server desktop application can able to run on Windows, macOS, and Linux. The server desktop application organizes your video, audio, and photo collections. Using Plex Media players you can access and stream your content collections. There are official clients available for mobile devices, smart TVs, and web apps.

rnNow install the package using dpkg command.

rnrn## Step-3) **Enabling Plex Repository**.

rnBy enabling the official Plex repo, you can update Plex on Ubuntu with apt package manager. The Plex deb package ships with a source list file. To see a list of files installed from a package, run dpkg with -L flag.

rnrn```
sudo dpkg -L plex media server
```rnNow open the following source list file and uncomment the line to get updates from Plex.

rnrn```
sudo nano /etc/apt/sources.list.d/plexmediaserver.list
```rn[![Img3](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling3.png)](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling3.png)rnAlso, you need to add the plex public key.

rnrn```
wget -q https://downloads.plex.tv/plex-keys/PlexSign.key -O - | sudo apt-key add -
```rnNow you can able to update your plex package list type command:

rnrn```
 sudo apt update.
```rnHere you can see plex repo has been added to your source list.

rn[![Img3](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling4.png)](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling4.png)rnNow you can view the plex server web access port by using netstat command.

rnrn```
sudo netstat -lnpt | grep Plex
```rn[![Img3](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling5.png)](https://www.technhit.in/wp-content/uploads/2020/10/plexTVinstalling5.png)rnHere you can see Plex server listening port 32400.
