Using SSH protocol not only access your remote shell. But also use it for transfer files between computers securely through encrypted communication. You can use any one way out of following:

rnrn
rn 	- scp (Secure Copy)
rn 	- sftp (Secure File Transfer Protocol)
rn
rn## **SCP (Secure Copy):**

rnscp stands for secure cp (copy), which means you can copy files across ssh connection. It is a very secure way to copy files between two computers because the connection securely encrypted.

rnscp uses by default the port 22, and connect via an encrypted connection or secure shell connection (SSH). Using scp you can copy files from your local computer to remote computer and remote computer to another remote computer.

rnrn### Examples of scp:

rn**Copy single file from local to a remote destination:**rn```
scp /path/to/source-file user@host:/path/to/destination-folder/
```rnAssume that we have a file test.txt in local directory <tt>/home/technhit/test.txt </tt>and want to copy to the destination server root@192.168.182.50 in tmp directory.

rn[![scp](https://www.technhit.in/wp-content/uploads/2017/01/scp.png)](https://www.technhit.in/wp-content/uploads/2017/01/scp.png)

rn**Copy single file from a remote server to your current local server:**

rnrn```
 scp user@host:/path/to/source-file /path/to/destination-folder
```rnAssume that we similarly have a test2.txt file on the remote server `/tmp/test2.txt` and copy to the local system.rn[![scp](https://www.technhit.in/wp-content/uploads/2017/01/scp2.png)](https://www.technhit.in/wp-content/uploads/2017/01/scp2.png)

rn**Copy single file from a remote server to another remote server**

rnrn```
 scp user1@server1:/path/to/file user2@server2:/path/to/folder/
```rnLet's assume that we have two remote server one is ***root@192.168.182.50**  *and another is*** technhit@192.168.182.51 ***and operating ***scp*** through our local system.

rnrn```
 scp technhit@192.168.182.51:/home/technhit/test3.txt root@192.168.182.50:/tmp/
```rn**Copy multiple files with one command**rnrnWe can copy multiple files using scp, file names followed by space with each.rn```

```rn#### **Copy files using wildcards:**

rn```
 scp /path/to/folder/*.ext user@server:/path/to/folder/
```rnFor example,  we want to copy all .txt file from `/home/technhit` to `/tmp/ `directory of host 192.168.182.50rn```

```rn**Copy a directory and all its contents to a remote server**rn```

rnrn## SFTP Secure File Transfer Protocol:

rnThe **SSH File Transfer** Protocol ( SFTP ) is a network protocol that provides file access, **file transfer**, and **file** management functionalities over the secure connection.

rnThe SFTP server function is enabled by default in Ubuntu, but if it is not enabled, comment out or add the line [`Subsystem `sftp` / `usr` / lib / `openssh` / sftp-server`] to [`/ etc / ssh / sshd_config`] After that restart ssh service.
