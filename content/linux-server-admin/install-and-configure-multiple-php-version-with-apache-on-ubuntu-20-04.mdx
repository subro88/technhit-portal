# Hi, Friends welcome to TechNHIT. In this article you will learn how to install and Configure Multiple PHP Version with Apache on Ubuntu 20.04

rnIt's very common when you working with Servers for Hosting web application, you needed multiple PHP version for the deferent web application as per their requirements and you have to manage these multiple requirements in a single server in a cost-effective way. Configuring multiple PHP in a single server makes you happy in this sense.

rn***So, in order to do this entire job perquisite, and environment I used.***

rnrn
rn 	- One Linux Box / VM / Container having Ubuntu 20.04LTS
rn 	- IP 10.0.50.51 (Local IP), I am doing this test in a local environment. You can replace it with Public IP for the production server.
rn
rn## **Let's go and logon to the system, and follow the steps. **

rn[embedyt] https://www.youtube.com/watch?v=HQlhytfwfj8[/embedyt]rn### Step 1) installing the Apache Server.

rnAfter updating the package list do install apache and modfcgid by typing the following command.rn```
sudo apt updaternsudo apt install apache2 libapache2-mod-fcgid
```rn### Step 2) installing PHP and PHP FPM

rn```
sudo apt install software-properties-commonrnsudo add-apt-repository ppa:ondrej/phprnsudo apt update rnsudo apt install php5.6 php5.6-fpmrnsudo apt install php7.4 php7.4-fpm
```rnwe are using PHP 5.6 and PHP 7.4 to configure with the Apache webserver. And we will use PHP FPM and FastCGI as an API

rnrn### Step 3) Configuring PHP with apache.

rnNow enable few modules that required for the configuration of multiple PHP versions with Apache. These modules are necessary to integrate PHP FPM and FastCGI with the Apache server.

rnrn```
sudo a2enmod actions fcgid alias proxy_fcgi
```rnNow configure websites on your Apache server, for testing purpose we are going to create two application directories for both PHP version to test the configuration.

rnrn```
sudo mkdir /var/www/php56-apprnsudo mkdir /var/www/php74-app
```rnNow create a file named index.php in each directory and push this phpinfo() HTML tag.

rnrn```
echo "<?php phpinfo(); ?>" > /var/www/php56-app/index.phprnecho "<?php phpinfo(); ?>" > /var/www/php74-app/index.php
```rnphpinfo() basically tales you about a brief of PHP information like version, module, server API, etc.

rnNow create an apache virtual host file and configure the required PHP version inside it. Go ahead and create the following host file under site available directory. Put the following configuration and tell the set handler to use your desire PHP fpm sock file.

rnrn```
sudo nano /etc/apache2/sites-available/php56.example.com.confrnrn
```rn```
<VirtualHost *:80>rn    ServerName php56.example.comrn    DocumentRoot /var/www/php56-apprn    <Directory /var/www/php56-app>rn        Options -Indexes +FollowSymLinks +MultiViewsrn        AllowOverride Allrn        Require all grantedrn    </Directory>rn    <FilesMatch \.php$>rn        # Apache 2.4.10+ can proxy to unix socketrn        SetHandler "proxy:unix:/var/run/php/php5.6-fpm.sock|fcgi://localhost"rn    </FilesMatch>rn</VirtualHost>
```rnSimilarly, create vhost for PHP 7.4 and configure the set handler

rnrn```
sudo nano /etc/apache2/sites-available/php74.example.com.conf
```rn```
<VirtualHost *:80>rn    ServerName php74.example.comrn    DocumentRoot /var/www/php74-apprn    <Directory /var/www/php74-app>rn        Options -Indexes +FollowSymLinks +MultiViewsrn        AllowOverride Allrn        Require all grantedrn    </Directory>rn    <FilesMatch \.php$>rn        SetHandler "proxy:unix:/var/run/php/php7.4-fpm.sock|fcgi://localhost"rn    </FilesMatch>rn</VirtualHost>
```rnNow enable both virtual hosts using following command a2ensite

rnrn```
sudo a2ensite php56.example.comrnsudo a2ensite php74.example.com
```rnAfter making all the changes restart Apache to reload new settings changes

rnrn```
sudo systemctl reload apache2rnsudo systemctl restart apache2
```rn### Step 4) Finally, Test Your Setup.

rnNow as we are in a local environment your system needs a local resolver to resolve the host. In order to do that in Linux system edit /etc/hosts file and put the following DNS resolver.

rnrn```
sudo nano /etc/hosts
```rnAdd following entry to the end of filern```
10.0.50.51/<your IP>/localhost   php74.example.comrn10.0.50.51/<your IP>/localhost   php56.example.com
```rnFor windows system edit host file in following path “C:\Windows\System32\drivers\etc”
