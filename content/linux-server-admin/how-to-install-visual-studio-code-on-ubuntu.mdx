rnrn## **Installing Visual Studio Code with the apt package manager:**

rnVS Code is available from the official Microsoft apt repositories. To install it, follow the steps below:

rnUpdate the packages index and install the dependencies by running the following command as a user with sudo privileges :

rnrn```
sudo apt updaternsudo apt install software-properties-common
```rn### Import the Microsoft GPG key using the following wget command :

rn```
wget -q https://packages.microsoft.com/keys/microsoft.asc -O- | sudo apt-key add -
```rn### And enable the Visual Studio Code repository by typing:

rn```
sudo add-apt-repository "deb [arch=amd64] https://packages.microsoft.com/repos/vscode stable main"
```rn### Once the apt repository is enabled, install the Visual Studio Code package:

rn```
sudo apt install code
```rnWhen a new version is released you can update the VS Code package through your desktop standard Software Update tool or by running the following commands in your terminal:

rnVisual Studio Code snap package is distributed and maintained by Microsoft. Snaps are self-contained software packages that include the binary all dependencies needed to run the application. Snap packages are easy to upgrade and secure. Unlike the standard deb packages, snaps have a larger disk footprint and longer application startup time.

rnSnap packages can be installed from either the command-line or via the Ubuntu Software application.

rnTo install the VS Code snap, open your terminal (`Ctrl+Alt+T`) and run the following command:

rnrn```
sudo snap install --classic code
```rnThat’s it. VS Code has been installed on your Ubuntu machine.
