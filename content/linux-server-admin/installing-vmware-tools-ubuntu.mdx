**VMWare tools** is a set of driver and utilities that enhance the performance of a guest system. And make the smooth interaction between a host system and the guest system. For example, the guest automatically adjusts screen resolution, coping file and text from host to guest and its vice versa moreover it enhance following utilities.rn
rn 	- It improves graphics performance and Windows Aero on operating systems that support Aero.
rn 	- The Unity feature, which enables an application in a virtual machine to appear on the host desktop like any other application window.
rn 	- Shared folders between host and guest file systems.
rn 	- Improved mouse performance.
rn 	- Synchronization of the clock in the virtual machine with the clock on the host or client desktop.
rn 	- Scripting that helps automate guest operating system operations.
